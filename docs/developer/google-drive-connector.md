# Google Drive connector retired

The optional Google Drive connector was removed on 2026-10-18 to retain the editor's account-free, frontend-only deployment model. The Google OAuth routes, server bindings and connection UI are no longer part of the application.

See the [MCP connector investigation and product decision](../explorations/2026-10-18-mcp-connectors-and-frontend-boundaries.md) for the original implementation, measured limitations, industry patterns and final removal scope. Local reference files and explicitly configured model services remain supported.
