# IM 独立会话、请求预算与当前范围

## 已实现

原顶部“新建”按钮调用清空唯一会话的逻辑。本轮改为真正创建独立会话，并增加历史会话选择器：每个会话拥有独立历史；标题取第一条用户请求；刷新恢复当前会话；旧 `agent_history_default` 数据继续保留并作为已有会话读取。会话索引使用 `agent_sessions_v1`，历史继续沿用原来的本地存储接口和按会话命名的键。

新建、切换会话停止旧模型请求、取消旧提案、清除旧输入和视图，但保留已加载的模型实例。生成回调同时检查提供者版本和会话版本，迟到回复不会进入新会话。用户请求在模型调用前保存；中断时保留请求，不将迟到或未完成输出保存为完整答案。

直接工具执行已经发出的改动不会因为切换会话而自动撤销。执行结束后，命令和结果写入发起会话：当前会话使用当前控制器，非当前会话重新读取原历史再追加，避免旧控制器覆盖较新的消息。回归测试覆盖异步写入期间切换，以及已有较新消息时的追加。

## 上下文预算

运行时每次模型调用前，对消息执行默认 6,144 UTF-8 字节预算检查。保留最近的完整用户轮次，工具结果不会被当成新轮次起点；调用和结果一并保留。仅裁剪本次请求消息，成功运行仍返回完整历史档案。裁剪时显示提示；当前请求或工具链本身已经超预算时，拒绝继续请求并提示缩小内容或拆分任务，不静默修改用户输入。

这是**消息字节预算，不是模型 tokenizer 的精确 token 计数**，也不包含提供者追加的系统提示与工具 schema；不能宣称已经精确匹配所有模型的上下文窗口。下一步可增加提供者级 token 估算/计数及系统、工具、输出预留预算。当前实现首先阻止历史无限增加导致每次请求无限增长。

不使用小模型自动总结并替换历史，避免把错误摘要当成事实。裁剪后模型可能无法参考较早的细节，完整记录仍可在原会话查看。

## 当前范围与执行边界

界面显示 DOCX、Excel 当前工作表/区域或 PPT 当前页。模型请求携带当前范围元数据作为参考数据，不持久化进聊天正文，不自动发送整份文档。

Excel 在明确选中多个单元格时支持：

- `计算选区的总和` / `sum selection`
- `将选区的总和写入 B11`
- `将选区按 B 列升序排序，首行为表头`

应用把实际选区转换成显式地址，然后复用范围校验和原生工具执行。没有明确区域时不从单个单元格推断“整列”。既有数字排序、求和与 PPT 工具的限制保持有效。

模型响应后和每个工具执行前重新检查取消信号，防止切换会话后才返回的模型响应继续修改文档。已开始执行的工具不能假定可以撤回；批次中尚未执行的工具记录取消结果并保持调用/结果配对。

## 验证

- 单元测试覆盖旧记录兼容、新建隔离、活动会话恢复、存储目标捕获、完整轮次裁剪、工具配对、过大请求拒绝、短历史前缀保留、临时范围不污染历史。
- 取消回归覆盖模型迟到工具响应不执行、工具批次中途取消、切换后的请求保留和迟到写入记录追加。
- 隔离 Chrome 验证新建为空、旧会话可恢复、切换后刷新恢复活动会话；亮/暗色截图检查通过。
- 浏览器运行时测试：100 条历史消息，本次模型请求保留 7 条，完整档案为 102 条。此处使用测试提供者验证请求边界，不是实际模型质量或速度测试。
- 新建 XLSX 实测 `计算选区的总和` 绑定 B2:B4，结果 60；原排序、SUM 写入和 PPT 操作复测通过。

会话目前按浏览器站点管理，尚未自动按文件分组；聊天历史沿用 localStorage，并非无限容量的持久档案。模型权重缓存仍为 IndexedDB。本轮没有修改用户正在编辑的 CSV 和模型比较 JSON，也没有切换默认模型。
