# Cold IM layout audit

Runtime 24e4a33, Chromium 151.0.7922.34, local preview 5193. [Driver](2026-10-05-im-cold-layout-audit.mjs) and [receipt](2026-10-05-im-cold-layout-audit.json) capture a fresh native Word page with explicit AI opt-in and CPU selection, before loading a model. The same-origin diagnostic global toggle opens the cold panel; this is not the normal ready-only sidebar entry. External requests were blocked by the harness; none occurred during this observation. Both context and browser closed, with no page errors.

At 1280×900 the panel occupies the rightmost 400 pixels. At 390×900 it occupies the viewport. Neither observation has document-level horizontal overflow. Expanded settings at 390 pixels have scrollWidth/clientWidth 389/389. Screenshots in `.scratch/im-current-1280.png`, `.scratch/im-current-390.png` and `.scratch/im-current-settings.png` were visually inspected. The editor is still showing its loading skeleton in the desktop screenshot; this observation does not prove document readiness, successful inference, keyboard accessibility, dark-mode quality or mobile device performance.

The main conversation view is restrained: header, conversation selector, three writing shortcuts and composer. Settings are separated from the ordinary conversation. The settings screenshot exposes a concrete consistency issue: the native file chooser says “Choose Files / No file chosen” in a Chinese interface and uses browser-default styling beside the application's other controls. A subsequent bounded improvement should preserve the real file input and its keyboard/screen-reader behavior while presenting a localized, consistently styled selection action and chosen filename. It must not introduce another confirmation or preview step.

The existing ready-only entry and query opt-in are retained. Prior design records explicitly require hiding the rail entry until model readiness; this audit does not authorize or justify changing that behavior. Model summary fidelity remains rejected separately. No product change, model download or inference occurred in this audit.
