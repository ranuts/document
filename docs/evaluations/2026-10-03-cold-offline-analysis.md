# Cached model fresh-process offline startup

All four configured GPU models and CPU 0.6B passed fresh isolated Chromium process startup from cache and actual hello inference, with no visible inference errors or page errors. Current built app shell was warmed online in a separate process and closed first. Each measured context starts with an unreachable local HTTP proxy, --proxy-bypass-list=<-loopback>, and offline emulation. An uncached same-origin request must fail, and the editor must be controlled by sw.js before inference. CPU explicitly disables navigator.gpu and uses the isolated ai-offline profile. These checks establish cached startup in desktop Chromium, not physical device reboot or cache eviction.

Initial offline-option-only diagnostics were unreliable: navigator.onLine remained true, and some uncached requests reached the preview server despite the requested offline context. Their success labels are not accepted as offline proof. Separate -control-fixed and -explicit-offline reports preserve those attempts; only -blocked-proxy reports count in the matrix. Failed optional spell script requests are recorded; hello inference and full editor API readiness passed. This does not prove offline spelling.

WebKit fresh-process offline navigation failed with an internal navigation error, before inference. This remains unresolved and must not be described as cold offline support for Safari/iOS. Previously verified WebKit warm reload is a different scope. Physical low-memory devices, browser eviction, offline document export for every editor and cold recovery from failed model initialization remain outside this matrix.

Matrix 2026-10-03-cold-offline-model-matrix.json records report and probe hashes. Run node docs/evaluations/probe-cold-offline-model-matrix.mjs for the GPU matrix; OFFLINE_CPU=1 OFFLINE_CPU_CHROMIUM=1 selects the CPU Chromium check. Profiles and preview 5193 must be available and unused by another process. Probe warms only the current app and first model; other configured model downloads must already be cached. No product or UI changes were made.
