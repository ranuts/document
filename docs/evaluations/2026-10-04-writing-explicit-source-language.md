# Explicit source-language prefix: paired diagnostic

Twenty-four native Word writing requests completed on default Qwen 1.7B: twelve known non-English summary/rewrite cases, each with current prompt and a candidate prefix identifying the fixture's known language. Complete captured Worker inputs are identical within each pair after removing exactly that prefix. The prefix also repeats name/numeric preservation, so this is a prefix intervention, not proof that language naming alone causes every difference. Temperature, schema, model-specific thinking flags, guards and served bundle were unchanged. Successful edits had exact native Undo/Redo; refused cases preserved original text. No preview cards or product changes.

Observed language improvement: German, Spanish and Portuguese summaries changed from English to source-language summaries visibly retaining proposal, quantity/value/date, prerequisite, pending inspection and unauthorized shipping. They still used two sentences instead of the requested one. Chinese rewrite moved from refused English/number-word output to a formal Chinese result retaining payment direction and explicit reverse-payment denial. Japanese summary became Japanese but omitted the passing-inspection prerequisite; Japanese rewrite added confirmation absent from the future payment source. Korean summary became Korean but changed unauthorized shipping to not-yet-completed shipping and kept the excluded parking meeting. Korean rewrite omitted five valves and was refused. German rewrite remained conversational; Spanish and Portuguese candidate rewrites returned unchanged source and were refused. Therefore the prefix is not adopted as production policy.

Language labels came from fixture oracle data, not automatic detection. Mixed-language documents, unknown languages and user language preferences are not solved. This fixed-order single-sample known-case comparison is not fresh heldout accuracy. Native Save, mobile resources, privacy and offline startup are outside this run. Browser context closed; independent checks require completed status and exact bundle/input/fixture identity. Run `python3 docs/evaluations/verify-writing-explicit-source-language.py`.
