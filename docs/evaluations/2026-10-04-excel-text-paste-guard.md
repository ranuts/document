# Excel callback insertion guard

Implemented guardExcelPasteCallbacks around the bundled worksheet protection, all/cell-lock and font-load continuation methods. Captured callbacks check operation activity and caller-provided target ownership. close() disables captured continuations, restores only still-owned methods and is idempotent. A per-view owner excludes overlapping guards; failed installation restores earlier patches. Caller must hold a blocking action and own native settlement, timeout/paste-state cleanup and history restoration. This guard is not yet used by set_cell.

Eight unit tests cover late font suppression, valid/expired callbacks, protection/cell/all locks, receiver/arguments/return preservation, avoiding later replacement overwrite, failed installation restoration and overlap/idempotent ownership. Tests failed before the helper existed, and ownership/installation regressions failed before those protections were added.

Native fault-injection probe compiles the exact current helper plus text-format scope. It delays real worksheet._loadFonts, invokes the original paste API, closes the guard / cleans native paste state on abort, then restores original formatting and history through the scope. Only after cleanup does it release the held original font loader. In both General and 0.00 formats, AbortError is reported, the late native continuation runs through the disabled guard, and the cell's complete before/after snapshot stays unchanged at numeric 30. The prior PPT-oriented helper instead wrote 123 after rejection under the same delayed stage (separate retained evidence).

A second current-source probe without delay/cancellation writes exact text 00123 under both formats, restores the original format, and passes one-step Undo/Redo snapshots. The probes record helper source hashes and no page errors. These are controlled native component tests, not IM integration, manual Stop tests or universal lock-phase cancellation acceptance.

Full suite: 121 files / 4,325 tests passed. TypeScript, scoped lint and diff whitespace checks passed; existing PromiseRejectionHandledWarning messages remain. No UI behavior changes until integration. Remaining work: native adapter completion/timeout settlement; bound original cell/history/redo; preflight protected/merged targets; blocking scope; validated quoted/text-mode planning; IM, Save/reopen acceptance.
