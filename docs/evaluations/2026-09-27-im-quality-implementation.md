# IM 质量改进实施与验证

## 已交付行为

普通聊天保持原入口。勾选“建议修改”后，可选择编辑请求、改写选区、摘要选区或翻译选区；翻译另选目标语言。写作需要 DOCX 文本选区，输入框内容作为额外写作偏好，不允许改变既定任务或来源。缺少选区不会擅自读取或修改全文。原文与提议内容同时展示，确认前不写入；取消、切换模式或选区变化会使旧提议失效。

WebLLM 写作使用独立 JSON Schema 解码，模型返回正文字段，UI 展示提取后的文本。其他本地后端使用同一输出协议和严格解析，未宣称支持约束解码。截断、原样改写/摘要、数字标记改变、明显的拉丁目标语言/CJK 输出冲突不能进入可执行预览。

确认后读回实际内容：DOCX 主正文比较一次文本替换，兼容 SDK 的 CRLF 段落标记和 lone CR 软换行；XLSX 检查宿主绑定单元格的显示文本。校验最多等待约 1.5 秒，失败不重试写入。状态区分“已发送”与“文本内容已核对”。页眉、页脚、绘图和未知正文定位能力不使用主正文读取冒充验证；显示“已发送”，由用户检查。读回不验证格式，也不能证明模型理解了请求。

[真实编辑器读回与 Undo 记录](2026-09-27-im-readback-results.json)涵盖插入、全选替换、多行替换及 C3 单元格写入。预览前后内容相同，确认后的内容可读回，撤销可恢复。

## 真实模型对照

环境：Apple M1 Pro、16 GiB RAM，Chrome WebGPU，WebLLM 0.2.85，q4f16_1，顺序加载两个引擎。固定任务、temperature=0、原生工具关闭。首轮是冷缓存；后续为热缓存。没有测量 GPU 峰值，模型列表中的显存数值来自 SDK 估算，不能作为实测峰值。

原始记录：

- [同任务首轮对比](2026-09-27-im-writing-comparison.json)：两款模型各四例，均有改写或摘要直接复制。
- [多语言及提示消融](2026-09-27-im-multilingual-comparison.json)：两款模型各九例写作，加各一例简化提示；保存了原始 JSON 和失败结果。
- [明确任务与保留格式后的对比](2026-09-27-im-final-model-results.json)：两款模型各八例，含六种翻译语言。此检查点在增加完整语言名称及文字体系守卫之前。
- [最终协议复测](2026-09-27-im-final-protocol-model-results.json)：包含完整语言名称、原样摘要拒绝与文字体系守卫，两个模型各八例。
- [真实 IM 完整操作](2026-09-27-im-ui-results.json)：最终版本使用真实 1.7B 模型生成西班牙语预览，确认后读回匹配，Undo 恢复；切换云端后写作控件实际隐藏。
- [IM 错误语言探测](2026-09-27-im-wrong-language-probe.json)：UI 的目标确为 es，1.7B 仍返回中文，未应用；据此加入完整语言名称及明显文字体系冲突拦截。

## 诊断与限制

4B 首次在隔离上下文加载，127 秒后出现 `NotReadableError`。直接读取该测试上下文的 75 条 Blob 记录，其中 39 条不可读；磁盘可用约 179 GiB。之后浏览器测试上下文丢失，无法继续原缓存修复。普通浏览器上下文重新下载并成功加载 4B，热缓存重载也成功。证据不足以认定是 IndexedDB 通用配额、GPU 或权限根因；记录为隔离上下文的大模型 Blob 缓存读取问题，没有据此修改 SDK 补丁。

数字守卫保留原始标记，避免把德语 `1,5` 错误折叠成 `15`。代价是正确的日期本地化、数字改写或文字数字转阿拉伯数字也可能被拒绝。文字体系守卫仅拦截明显冲突，不能识别西班牙语与葡萄牙语的混淆。人名、否定、单位和整体语义仍需对照原文检查；没有用 JSON 合法率包装成任务成功率。

独立审查发现的小数逗号和 SDK 软换行问题，均以失败测试复现后修正。还将页眉/绘图等不受主正文读取覆盖的目标明确降级为“已发送”。UI 实测发现 ranui 自定义控件会覆盖浏览器的 hidden 样式，已增加对应隐藏规则并验证计算样式。

亮暗模式已检查实际 IM 控件和预览颜色：亮色背景/文字为 `rgb(255,255,255)` / `rgb(23,23,23)`，暗色为 `rgb(26,26,26)` / `rgb(237,237,237)`。修复了自定义下拉框在工具栏缩为 26 px、只剩箭头的问题；实际宽度恢复为约 160 px，随工具栏换行。

最终校验：72 个测试文件、3,575 项测试通过；lint（含类型检查和 Docker Compose 配置）及生产构建通过。已有大块打包、Node 模块浏览器外置及异步 rejection 警告仍存在。未构建完整 Docker 镜像。
