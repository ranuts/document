# Native CPU cancelled-stream prefix recovery

The preregistered driver at 07d98fd completed one actual stream cancellation and one resumed completion on a fresh CPU Qwen2.5 0.5B engine. No generated output was substituted. After the first role-only chunk and first text chunk `AL`, its callback aborted the signal. Both observed chunks have null finish_reason; the SDK rejected with AbortError/Operation aborted rather than returning normally. The subsequent request returned `BRAVO.` with 655 cached prompt tokens out of 669. These observations support changed-label recovery after this actual partial stream, not a stream that finished before cancellation.

Cancellation-to-SDK-settlement was 0.590 ms, measured inside the page callback; this is not UI input latency, paint, INP or an independent measurement of all native backend activity stopping. The first call took 20525.385 ms including prefill, resumed call 816.995 ms. One run/fixed order/one model do not establish general latency performance. The period remains a strict formatting miss, while the current label is correct.

Model/WASM hashes match the recorded artifacts. Actual served client bytes match their recorded disk SHA-256. The standalone diagnostic injects COOP/COEP and requires native Chromium JSPI; it does not operate the product Stop button or certify deployed CSP. The driver awaits first-call settlement before issuing the second call, then exits the engine and closes its browser. Captured page errors are empty, contextClosed true and process exit 0. Product source/defaults were unchanged.

`python3 docs/evaluations/verify-cpu-prefix-stop.py` checks frozen driver, partial native callback evidence, abort rejection, changed-label output, cached-token counter, model/WASM/served-client identities and cleanup. This is not comprehensive cancellation recovery for prefill, worker loss, model switching, larger models, context trimming, cross-document isolation, physical mobile, offline/PWA or semantic writing quality. Actual product integration remains the next relevant scope.
