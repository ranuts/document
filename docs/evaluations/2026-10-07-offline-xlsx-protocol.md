# Current-build cached CPU Excel offline lifecycle

Warm the current Excel editor and real default CPU model in the existing desktop Chromium profile while online, then close the seed browser process. Restart with browser offline emulation; require the homepage to be served by the service worker. Load a new workbook and the cached default CPU model, submit the explicit tools instruction to set B2 to OFFLINE_XLSX_20261007, then compare exact native B2 values before/after Undo/Redo. Save using the actual editor save button and download fallback. Inspect the saved XLSX ZIP/XML independently. Close the browser, then restart offline and open the saved workbook through the homepage file chooser; compare the exact native cell value.

Retain resource failures and page/chat errors. This covers one explicit operation on warmed desktop Chromium under offline emulation, not physical network disconnection, a fresh install, whole workbook formatting, arbitrary commands, installed PWA, mobile or WebKit. No API output substitution or capability spoofing. Frozen application assets remain the previously evaluated production build; no product changes. Weights and saved workbook binaries remain local and ignored.
