# Worker event markers: immediate navigation versus controlled Home

Exploratory instrumentation only at owned forwarding origin 5194; product source is unchanged f2eb0ed. The diagnostic server serves built dist/sw.js with a short prefix: emit an owned same-origin fetch marker at bootstrap, and register additional install/activate listeners that emit markers via waitUntil. Responses for the instrumented script use explicit JavaScript/cache/scope/CORP headers rather than the original forwarded compressed response. This intervention changes script bytes, scheduling and headers, so it is not unchanged-product acceptance evidence.

Immediate Home local-file navigation: the server receives bootstrap, but no install-enter or activate-enter marker within the observation. Actual registration remains installing, controller null, Cache API names empty; native file import text is exact. This narrows the symptom to a stage preceding observed install-marker completion, not a failed resource response inside a completed cache installation. Absence of a telemetry request alone does not prove an event was never dispatched or identify browser internals.

Positive control uses the same instrumented script/server/context pattern but waits for Home controller before opening the same DOCX. It receives bootstrap, install-enter and activate-enter in order, Home controller becomes the production path, and the editor retains activated worker/control plus runtime/core caches. Thus this instrumentation can observe install/activate on the successful timing path. Both browser/context/server cleanups complete; page errors remain empty. Instrumented results agree with earlier unchanged-script timing observations 7cc132b, but remain diagnostic rather than a product fix.

No blocking UI, arbitrary delay or registration restart is justified yet. The immediate-navigation startup/install transition needs a precise lifecycle remedy or verified browser limitation; waiting at Home is still a probe prerequisite only. No global offline, actual Safari/iOS, process restart, visual layout or semantic quality acceptance is claimed. No new product build/tests are run for these evidence-only probes.
