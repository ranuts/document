# IM 面板设计系统与交互优化

## 依据与方向

指定的 ran 文档站 `packages/docs/index.md` 是首页入口，组件由 `HomeCinematic` 渲染。实际规范读取同一文档包的 `src/ranui/design-system/index.md`、`design-guides/index.md`、`information-architecture/index.md` 和 `style-tokens.md`。它们要求按语义角色使用 token、用 4px 间距尺度、区分尺寸与间距、验证亮暗/窄屏/焦点，并优先组合已有组件。

面板是**当前文档的工作区**：用户先识别会话和文档范围，再阅读对话，最后在底部提问或执行写入。视觉上保持文档编辑器的克制，行动主次是“发送”优先、“写入文档”明确但次级，设置和技术状态不争夺正文位置。

## 本轮改动

- 顶栏保留名称、状态、设置和关闭。新建会话按钮改为加号，紧贴历史会话选择；选择与创建属于同一组，避免原箭头图标被误认作弹出窗口。
- 文档范围独立显示为小型说明，仅范围变化时更新文字；不设 live region，避免 Excel 键盘导航时每个选区变化都被读屏播报。
- 设置中的 provider、模型和 API Key 补齐七种界面语言的可访问名称；展开设置时聚焦 provider，Escape 收起并把焦点还给设置按钮。
- 打开面板后聚焦输入框；新建/切换会话仍保持原有的草稿、历史和模型生命周期处理。
- 统一消息列、输入区和写入按钮的间距、层级、边框、文字角色与焦点，使用 `--ran-color-*`、`--ran-space-*`、`--ran-size-*`、`--ran-text-*`、`--ran-radius-*` 和 `--ran-focus-ring`。蓝色只用于焦点/链接，主操作沿用 ranui 单色主色；亮暗切换无需独立硬编码配色。
- 保留现有 ranui builder、`r-select`、`r-input` 等控件，以及独立的 ChatView 安全 Markdown/流式渲染。没有为了外观将历史/工具/审阅状态改写成另一套对话存储或组件协议。

## 验证与边界

单元测试覆盖会话控制布局、设置控件名称与 Escape 焦点；全量测试 84 文件、3,657 项通过，`lint:ts` 和生产构建通过。隔离 Chrome 中使用本地对话夹具检查亮暗和 390px 窄屏：面板无水平溢出，设置展开与 Escape 收起正常。浏览器验证未调用真实模型，也未触碰用户文档。

后续可单独评估将工具活动/消息迁移到 ranui `r-conversation` 的事件投影；它要求重新接入流式、历史、写入与审阅卡片，属于独立架构改造，不应和本轮视觉调整混在一起。
