# Evidence-first summary diagnostic

Freeze the [candidate](2026-10-05-summary-evidence-candidate.json) before inference. Reuse all four [previous concise fixtures](2026-10-05-summary-concise-cases.json); all are now observed development cases, not heldout. Fresh Chromium/native Word/model per product/evidence row, product then evidence, no retry or tuning. Product 5cd8f80/core 1791160815, local CPU Qwen3 0.6B Q4_K_M, temperature0/top_p0.8/max512 per stage, existing JSON/native guards unchanged. No production changes or model download.

Evidence variant first generates a JSON spans array of source quotations. Count this exact stage request using the current patched runtime; require promptTokens+512+1 <= contextTokens. Reject malformed output, length termination, empty/non-source spans or >16 spans. Exact substring membership is a lexical check, not proof of coverage or semantic fidelity. Then preserve the original task JSON data and provide the original source plus generated evidence spans to the frozen summary system. Apply identical final transformation to provider counting and completion. Capture both requests, exact counts, raw extraction, validity/failure, raw summary/native text, Undo/Redo, errors and cleanup. Stage1 failure must leave the original document, never fall back silently. Overall timing includes extraction overhead. This changes prompt roles/content and number of inference calls together; do not isolate a causal feature.

Manual acceptance requires both selected evidence covering every instructed relationship/status and the final one shorter source-language sentence preserving every instructed fact, with no invention or altered condition. Any failure blocks promotion; even all four successes require new seven-language heldout evaluation, Stop/retry/cache/budget regression and performance acceptance before product adoption. Retain all failed rows.

Motivation only: [FASum](https://aclanthology.org/2021.naacl-main.58/) extracts/integrates factual relations using a trained graph-attention model. This prompt-only quotation experiment is not FASum, does not reproduce its reported results and is not claimed state of the art. The experiment tests whether separating source selection from compression helps this actual small local model; extraction could itself omit facts or compound errors.
