# Active local source recovery integration

Local imports now retain their active-tab source before stamping the generated saved id. A saved route reads history authoritatively: a real row restores its newest snapshot, and only a successful read proving no row exists permits the matching active-tab source fallback. History storage failure or missing snapshot in an existing row does not silently revert to original bytes. Reading an unedited import still creates no history row. Successful new/URL opens release the prior source; failed conversion keeps it. Explicit history deletion/clear also removes source records and reports failure if source deletion fails.

The replacement editor retires the previous autosave session before awaiting source persistence/cleanup. Attempt ids and successfully mounted ownership are separate, so a newer failed attempt does not orphan the mounted document's delayed session finalization. Behavioral regression tests reproduced writing replacement bytes under the old document id, and an absent URL id after a newer conversion failed; both now pass. Source/storage failures remain best effort rather than blocking native editing.
