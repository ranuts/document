# Excel 与 PPTX 的 IM 直接操作

本轮扩展当前文档 IM 的确定性执行路径。明确的指令由应用解析、验证参数、调用编辑器 SDK 并读回结果，无需模型加载完成或远程 API key。

## Excel

| 用户指令                              | 行为                                                       |
| ------------------------------------- | ---------------------------------------------------------- |
| 将 A1:C10 按 B 列升序排序，首行为表头 | 保留第一行，在指定区域内按 B 列升序移动完整数据行          |
| 将 A1:C10 按 B 列降序排序，无表头     | 所有指定行参与降序排序                                     |
| 计算 B2:B10 的总和                    | 读取数值，展示总和，不移动选区或写入                       |
| 将 B2:B10 的总和写入 B11              | 在显式指定的空单元格写入 `=SUM(B2:B10)` 并验证公式和计算值 |

英文支持 `sort A1:C10 by B ascending with header`、`sum B2:B10`、`sum B2:B10 into B11`。

排序要求明确区域、排序列、方向及表头策略。当前支持数字键列，拒绝空值、逻辑值、非有限数值、数据行公式、合并单元格、受保护工作表、筛选、格式表和透视表；最多 5,000 个单元格。SDK 原生排序移动整行，不通过读取字符串再粘贴重建数据。执行后比较完整行集合、数字顺序和原表头，防止仅排序一列导致数据错位。

求和按 Excel `SUM(range)` 规则忽略文本、空白和逻辑值，错误值和溢出给出提示。读总和可包含公式结果。写公式时要求源区域没有公式，避免目标虽在源区域外但被源公式引用而形成间接循环；目标必须是区域之外的单个空白、未合并、未保护单元格。当前“累加”指区域总和，不包含逐行累计列的自动生成。

## PPTX

| 用户指令            | 行为                                   |
| ------------------- | -------------------------------------- |
| 新增一页幻灯片      | 使用编辑器当前布局规则新增一页         |
| 复制当前幻灯片      | 仅允许当前页为唯一选中页，调用原生复制 |
| 切换到第 3 页幻灯片 | 检查现有页码并跳转                     |

英文支持 `add a slide`、`duplicate current slide`、`go to slide 3`。拒绝母版视图；新增和复制检查只读状态。新增/复制验证页数增加一页且原页仍存在，导航验证当前页码。已有 `get_presentation_text` 工具继续用于非破坏性读取幻灯片文字。

本轮没有实现整套演示文稿自动生成、文本框内容改写、图表和图片自动排版，也没有新增删除幻灯片命令。复杂或目标不明确的操作先提示可用命令和明确范围。

## 验证过程与结果

1. 新增命令解析和工具测试，确认实现前失败，再实现功能。
2. 隔离 Chrome、新建 XLSX/PPTX、禁用该测试环境 WebGPU、无 API key，通过 IM 实际提交中文指令。
3. Excel 数据为名称/金额/编号三列，金额 30、10、20：升序得到乙/10/1、丙/20/2、甲/30/3；降序顺序相反，表头不变。B5 写入 `SUM(B2:B4)`，计算值为 60。
4. 输入 TRUE、5、text 后求和结果为 5。D3 引用 F3 时，把 D3:D4 总和写入 F3 被提前拒绝，目标没有公式。
5. PPTX 从一页新增为两页、复制为三页，最后导航到第一页；实际 SDK 页数和页码正确，没有错误提示。
6. 全量 78 个测试文件、3,629 项测试通过；TypeScript 与 oxlint 通过。生产构建单独验证。

测试只使用隔离环境的新建文档，没有操作用户正在编辑的文档。默认模型、缓存方式及其他五种语言的意图覆盖范围未发生变化；新增提示目前为中文/英文。
