# Landing prefetch and quiet observation jointly permit saved Word migration

The [new diagnostic](2026-10-03-sw-saved-no-prefetch.json) retains real baseline/candidate build bytes and the old native Word edit/save checkpoint. On the landing page, an init-script listener invokes the existing prefetcher's stopWarming hook before its DOMContentLoaded handler. It records the hook present and leaving=true. The first controller VERSION observation is delayed 40 seconds, exactly as in the earlier [quiet-observer-only failure](2026-10-03-sw-saved-quiet-observation.json). No Worker is stopped, no cache is cleared and skipWaiting is not called manually.

At the first observation the candidate vendor is controlling the page and there is no waiting Worker. The saved old file reopens with exact sampled OLD_UNSAVED_docx text. Candidate native insertion, Undo, Redo, visible-toolbar Save and exact sampled-text reopening complete. Same-context offline navigation has isolated parent/iframe, effective cached vendor policy, blocked inline/event/controlled-foreign script probes, an uncached fetch rejection and zero upstream responses. Legacy eval still remains permitted by the experimental native policy. This remains a text/control proof, not full formatting fidelity, physical-device acceptance, model inference or deployed hosting verification.

The diagnostic fetch observer records no prefetch-originated fetch before the quiet interval ends. Later user interaction resumes the existing prefetcher and records fetches; the run does **not** claim prefetch is absent forever. Artefact bytes and SW source are unchanged; runtime prefetch state is deliberately altered for diagnosis.

The base report's passed=false and process exit 1 are retained because only Word ran while its success gate requires three native document types. There is no report error and its Word migration, cold/native and offline rows complete. completeMigrationPassed remains false: this one-type diagnostic intervention is not a validated automatic production migration. The scoped verifier checks those individual outcomes rather than misreading the global flag.

Compared with the prior identical quiet interval, stopping landing warming changes this observed outcome. The experiment supports an interaction between prefetch/lifecycle timing and promotion; it does not establish that stopping prefetch alone suffices, that 40 seconds is necessary, or that a particular browser internal request is defective. A reactive controllerchange observer and separate immediate-promotion control should isolate observation interference before a product change. Do not ship a fixed sleep or remove offline caching based on this combined intervention.
