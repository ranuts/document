# Consistent summary request: diagnostic design freeze

Actual relation-summary requests contain a general assistant system message, diagnostic suffixes and a user message combining three-operation instructions, a plain-body output rule and a later JSON-object output rule. This establishes competing wording and redundant non-summary instructions, not the causal explanation of any observed failure. The earlier WebGPU Qwen3 compact rewrite diagnostic reversed negation; a shorter prompt is not presumed safer or better.

The frozen candidate uses one summary-specific system message and the unchanged original task JSON as the user message. It has one JSON-only output contract and preserves reference-content isolation, source language, actor-action/prerequisite/current-state relations, names, numeric/date/currency/unit tokens and meaningful list structure. Schema, model, generation options, product validation and native application remain identical. This is a diagnostic request transformation, not a shipped refactor or weakened refusal gate.

Compare the frozen relation-suffix route with this candidate using other unused sources before adoption. Existing archive/reservoir sources are observed development data and cannot provide heldout acceptance. Freeze new cases and an executable driver before inference. The driver must extract exactly one complete original JSON object, verify unchanged task data, transform both token-count and completion requests identically, reject ambiguous extraction, record raw inputs/outputs, retain failures and close its browser in finally. Do not concatenate a new user suffix after the JSON.

Assess semantic fidelity, concise form and natural wording separately from native Undo/Redo. This whole-request comparison cannot isolate whether length, role placement, unrelated instructions or output-rule consistency caused differences. Even all-case success requires broader seven-language/operation transfer, actual default models and practical latency. No production prompt/default changes are authorized by diagnostic success alone.
