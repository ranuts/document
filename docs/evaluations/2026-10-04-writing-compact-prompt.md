# Compact rewrite prompt: rejected after negation reversal

The six previously committed semantic-pair fixtures run with the same Qwen3-1.7B model, production temperature/schema/thinking setting and guards. Route-local Worker instrumentation replaces only the user writing prompt with two concise instructions plus the unchanged request JSON. The instructions explicitly ask for formal style, preservation of action performers/recipients, negation, approval status, prerequisites and exact numeric/date/name tokens. This is a rewrite-only experimental prompt, not a candidate for summary/translation or a shipped change. It omits some original explicit unit/list-structure rules; those are not covered here.

Four English outputs remain identical to the source and are refused. The Chinese approved case is unchanged from baseline. The not-yet-approved source produces `林青已批准在 2026-10-12 支付 640 EUR。` and is applied: it reverses pending approval into granted approval. The source is `哎，林青还没有批准在 2026-10-12 支付 640 EUR 啦。`. Name, number, currency and ISO date remain exact, so current validation does not catch the opposite claim. Native Undo/Redo is exact on the two applied results, but correct editor history is not proof of writing fidelity.

Decision: reject this prompt. It does not improve English formal rewriting and introduces an explicit negation failure. The independent verifier confirms complete Worker requests differ only in the user prompt, unchanged request JSON/bundle identity, four refused source-preserving results and the exact opposite-approval output. It does not infer overall accuracy or establish why the model fails. No product prompt/default/guard changed.

Scope: known purpose-built six-case diagnostic, one fixed-order sample, warm owned Chromium WebGPU with route-local raw/input recording and isolation headers. Context closed normally; no page errors or previews. No real-device, Save/offline/privacy certification or statistically reliable latency comparison. Neither prompt length nor a single instruction's effect is isolated: the whole prompt changed, so do not conclude that shortening alone causes reversal.
