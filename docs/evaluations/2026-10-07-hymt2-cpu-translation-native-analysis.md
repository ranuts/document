# Specialized CPU translation screen

The fixed Tencent Hy-MT2-1.8B Q4_K_M GGUF artifact was downloaded and verified against its public repository revision, size and SHA-256 before execution. Model bytes remain outside Git. The [official model card](https://huggingface.co/tencent/Hy-MT2-1.8B-GGUF) provides GGUF artifacts, supported languages and translation prompts; its published metrics are not evidence of this project's acceptance.

All seven known-source cyclic translations completed with stop in a real isolated Chromium context using the project's current source-built CPU SDK/native pair. The receipt binds the actual client and WASM bytes. The process exited 0, and browser/context/server closed. This establishes scoped SDK compatibility for the examined model, not the product model-selection path or physical devices.

Bounded manual review: 1 narrow pass, 4 failures and 2 uncertain. German-to-Spanish retains the examined facts and literals. English-to-Japanese and Portuguese-to-Chinese change ISO date representations; Japanese-to-Korean transliterates required original personal names and renders one name inconsistently. Korean-to-German has article errors, adds identity/signing ownership and turns a checklist into a report. Chinese-to-English masking terminology and Spanish-to-Portuguese grammar require further review. Improved Chinese inventory-taking wording is insufficient to establish complete fidelity while dates change.

These are limited development judgments, not native-speaker certification or representative translation accuracy. Plain translation prompts plus preservation instructions and unconstrained output differ from the product JSON writing pipeline. Caller sampling parameters, CPU context 2048 and four threads are recorded; this is one stochastic sample per direction, not deterministic quality certification. No rewrite/summary results, all-direction translation coverage, editor application, model/default adoption or offline/device acceptance are claimed.
