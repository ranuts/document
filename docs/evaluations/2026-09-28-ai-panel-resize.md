# AI 面板边界拖动

AI 面板左侧增加 8px 可操作分隔线，使用同一个 CSS 宽度变量同步调整面板和文档 iframe。桌面面板最小 320px，最大为视口减去 360px（狭窄窗口优先保证面板最小宽度）；480px 以下保留覆盖式布局并隐藏拖动入口。

支持鼠标和触摸 Pointer Events，拖动期间捕获指针并添加临时遮罩，避免进入 iframe 后丢失事件。松开时按最终位置计算，取消、丢失捕获、窗口失焦和页面离开均清理遮罩；拒绝第二根指针重复开始拖动。拖动中禁用 iframe 宽度过渡和文字选择。

分隔线可通过 Tab 聚焦，左右方向键调整 24px，Home/End 调至最小/最大宽度；提供 separator 角色、方向和当前值。宽度保存在当前站点 localStorage，刷新后恢复，窗口缩小时自动限制实际宽度。存储不可用不阻断操作。亮暗模式使用现有边框颜色变量。

验证：相关面板测试 19 项通过，静态检查和生产构建通过。独立 Chrome 中打开测试 DOCX，实际拖动后面板 559px、文档 iframe 721px，总宽度等于 1280px，遮罩已移除；刷新恢复 559px。已生成亮暗模式截图。没有加载真实模型或修改用户文档。
