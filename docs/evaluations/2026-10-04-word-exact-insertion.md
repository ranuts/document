# Word exact cursor insertion

The planner now binds explicit English `Insert exactly this plain text at the cursor: ` and Chinese `请在当前光标处逐字插入以下文本：` commands to their entire terminal text. The schema permits only `insert_text` with that exact source or `unsupported`; independent result validation rejects changed text. This reuses the existing native insertion and history behavior, without a preview or confirmation step. Other requests retain the existing capability selection.

Two actual IM requests used browser-local WebGPU Qwen3-1.7B-q4f16_1-MLC on new Word documents: six mixed Unicode lines and 35 repeated `Extraordinary` segments with a Unicode suffix. Captured outgoing Worker requests each contain the exact source as the sole text enum. Native document text matches the source after normalizing native line endings and accounting for the terminal paragraph break. Both native Undo snapshots equal the empty document and both Redo snapshots equal the complete inserted text. There are no recorded page errors, visible message errors, or preview cards.

The raw report is deliberately preserved: its multiline `literalExact` is false because the driver normalized CRLF only, while Word's `GetText()` returns lone CR for internal line breaks. `verify-word-exact-insertion.py` explicitly normalizes CRLF and lone CR; it does not change any other characters. The long-word comparison is true in the original report. Driver SHA-256 is checked against the preserved executed bytes.

Unit tests cover both command languages with boundary spaces, emoji, quotes, a literal backslash-n, tab and newline, and reject a provider response that appends characters. Three negation/discussion controls show that these prefixes do not force the closed insertion grammar; they do not prove that arbitrary model interpretations of negation are safe. Existing selection replacement and review-setting coverage remains passing. The final build, 116 test files / 4199 tests, and lint passed.

Scope: the browser run uses English commands, a warm profile, network available, service workers blocked, and two blank Word documents. Chinese commands and additional special characters have unit coverage only. This does not certify arbitrary paraphrases, Word layout or font rendering, Save/reopen, cold offline startup, physical devices, network privacy, or broader model writing fidelity. Altered insertion responses currently display the existing generic request error. No model default or UI changed.
