# 本地文档助手优化设计

依据：用户附件 `pasted-text-1.txt`（2026-10-02），授权继续分析和优化、自主执行。此设计接续 9 月的实验分支，不把通过单测等同于产品验收。

## 目标与范围

浏览器内完成文本推理；对话和文档内容不发送至服务器。首次允许下载模型、分词器和自托管运行时，之后验证完整断网启动。桌面优先，资源受限设备使用较小的 CPU 模型。移动设备内存不存在可依赖的统一硬阈值；根据能力、加载失败和实测决定降级。

首批完成文本聊天、流式输出、停止、重试、模型选择、参数调节、上下文预算、历史管理、导出和通过 IM 操作当前 Word、Excel、PPT 的原生文档工作流。语音、视觉和本地 RAG 是按需扩展点，不纳入当前必需交付；图像/视频生成、浏览器操作不进入此次实现。

## 引擎调度

保留 WebLLM 0.2.85 和 wllama 3.6.1，避免未经验证的升级。新增独立 LocalInferenceProvider，保持 LocalLLMProvider 的显式 preload/dispose 接口。GPU 检测必须实际 requestAdapter；无 adapter 或探测异常直接 CPU。WebLLM 初始化失败先释放资源再使用 wllama CPU；取消不能触发降级，释放后不得重新开始加载。候选列表须保证失败尝试次数有限，错误保留每个引擎的诊断原因。

每次加载单飞；消息生成串行，未加载不隐式下载。流式输出开始后不重放请求至另一引擎。GPU 丢失后显示可重试状态，重试允许降级，避免重复输出和重复编辑。WebLLM 使用 Dedicated Worker，wllama 复用自身的 Worker。CPU 模型可自托管，官方模型源固定 revision，下载字节与显存估算分开。

## 隐私与产品交互

产品入口仅允许浏览器本地引擎，通用 agent-core 可保留远程 provider 给其他消费者，但产品 UI 不提供云端上传捷径。历史默认仅内存，保存需明确开启；开启后使用 IndexedDB，关闭保存不自动销毁已有用户记录，提供单会话和全部历史删除。模型缓存独立管理，导出在浏览器生成文件。设置展示实际引擎、模型和生成统计，并支持受限的生成参数。

模型及对话 HTML 均视为不可信，维持安全 Markdown 与 textContent 渲染。CSP 按真实脚本、Worker、WASM 和模型来源设计，不能阻断离线编辑器。后台下载与首载的自动加载行为需清晰展示且可取消。

## 质量与验收

小模型只作为可用性兜底，不声称七语言质量达标。七语言改写、摘要、翻译分别测试语言、数字、日期、否定、负责人及注入样本。模型模板由 SDK 应用；文档上下文明确标记为数据，不能授予模型直接执行任意代码的权限。按用户最新要求，合法的文档操作直接执行，不增加预览卡片或重复确认；执行前校验请求与编辑目标，执行后使用文档原生撤销和保存。模型输出通过校验不等于语义质量通过。

自动化覆盖 GPU 探测异常、初始化降级、所有候选失败、取消/释放竞态、串行请求、重试、历史选择保存及删除、导出和参数边界。真实浏览器覆盖 GPU 与强制 CPU、首次下载、断网刷新、存储错误、Worker 故障、亮暗与窄屏、键盘操作。正式设备验收包括 Apple Silicon、Windows 集成 GPU 和资源受限设备；缺失设备证据必须记录未验证，不能以模拟结果代替。
