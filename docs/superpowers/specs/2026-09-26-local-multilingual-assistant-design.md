# 浏览器本地多语言写作助手设计

用户已确认：无需远程 API key；先做选区润色、翻译、摘要；覆盖中文、英文、日文、韩文、德文、西班牙文、葡萄牙文；按现有设计系统支持亮色和暗色。2026-09-26 授权整理整体计划并开始实施。

## 技术选择

复用现有实验 AI 面板和 provider 接口。WebLLM 使用 Dedicated Worker，不修改 PWA Service Worker 的推理职责。固定 SDK 版本，发布前还需固定模型文件 revision 与兼容 WASM；Qwen3-1.7B 是暂定基准，Qwen3.5-2B 是对比候选，均不是已通过质量验收的默认产品模型。Pi、Jev 不进入首批实现。

模型列表显示官方 GPU 内存估算，不能将其误写为下载大小。缓存检查只是权重缓存提示，不保证完整离线可用。首次下载须用户明确点击加载；发送消息不能绕过加载要求。无 WebGPU 时保留普通编辑，不自动选择需要 key 的服务。

## 模块与生命周期

- provider：模型初始化、就绪判断、重试、生成取消、请求串行化、资源卸载。
- Worker：运行 SDK 引擎，主线程只接收进度及生成结果。关闭资源时终止 Worker；失败允许重新初始化。
- writing-task：生成固定任务提示。界面语言不决定文档输出语言；润色和摘要保留原文语言，翻译显式选择七语言中的目标。
- 选区工作流：读取选择与文档标识，生成独立建议，展示原文和结果，用户确认后通过编辑器 API 写入。只处理文字文档；不执行生成代码或 HTML。
- 评测：固定七语言语料与任务矩阵，采集冷启动、热启动、生成时间、质量和取消结果，不将 mock 测试等同于实际推理。

首批编码交付推理基础与多语言任务/评测基线；选区应用界面及实际设备验收按实施计划继续推进。AI 仍通过 `?agent=1` 开启，公开功能文案继续说明未正式发布。

## 编辑与隐私边界

同一文档修改串行；应用前验证 editor 实例、文档标识、修改版本及选区定位，任何变化使建议失效。仅对比选中文字不足以保证定位相同，不能作为发布级保护。用户可撤销；不宣称自动保留复杂格式。模型只生成建议，不能自行执行操作。

本地任务默认不保存文档和对话内容；现有通用聊天持久化须在面板阶段改为用户明确选择保存。模型缓存与文档/对话删除分开。OPFS 可恢复生成保持关闭。

## 验收与发布

自动化覆盖初始化失败重试、加载时取消、模型卸载、生成串行、能力检测、七语言提示与翻译目标、文档切换和选区失效。真实浏览器覆盖七语言润色/摘要和与中文、英文互译；人工检查语言、原意、数字、术语和自然程度。评测不合格时限制功能或选择较大模型，不用总体平均分掩盖单语言失败。

正式发布前检查 Windows 集成 GPU、Apple Silicon 和至少一种资源受限设备；验证断网后重新打开、存储不足及 GPU 丢失；检查亮暗模式、键盘和读屏。补齐实际分发模型许可。更新 README/SEO 必须基于已验证功能。
