## B. 输入特征

| 特征                                                                  | 覆盖                                        |
| --------------------------------------------------------------------- | ------------------------------------------- |
| 文件名：ASCII / CJK / 空格括号 / 全角标点 / emoji / `&%'!` / 180 字符 | FN（xlsx 全部；docx CJK+空格）；pptx ⬜     |
| 体积：KB 级                                                           | 全部合成用例                                |
| 体积：MB～60MB                                                        | 🌙（EMP deck 6.5MB 产物）；固定用例 ⬜      |

| HTML 伪装 .xls/.xlsx                                                  | HX + 单测                                   |
| 垃圾字节 / 截断                                                       | OF（垃圾）；截断 ⬜                         |
| 多 sheet                                                              | ER                                          |
| 合并单元格 / 冻结窗格 / 公式 / 图表 / 页眉页脚 / 修订 / 嵌入对象      | 🌙（取决于语料）；参数化生成 ⬜             |
| 图片（URL 插入）                                                      | ER                                          |
| 密码保护                                                              | 显式排除（CORPUS_EXCLUDE）；期望行为用例 ⬜ |
