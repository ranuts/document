로컬 파일 열기, 편집, 형식 변환은 내 기기에서 이루어지며 문서 처리 서버가 필요하지 않습니다. 소스 코드는 공개되어 있으며 직접 확인하거나 호스팅할 수 있습니다.

Word(DOCX), Excel(XLSX), PowerPoint(PPTX), CSV를 지원합니다. 복잡한 레이아웃이나 특수 글꼴은 다를 수 있으므로 공유 전에 확인하세요.

## 할 수 있는 일

- 로컬 파일 열기, 편집, 형식 변환은 내 기기에서 이루어지며 문서 처리 서버가 필요하지 않습니다. 소스 코드는 공개되어 있으며 직접 확인하거나 호스팅할 수 있습니다.
- **주요 형식 편집** — DOCX·XLSX·PPTX·CSV 를 서식 그대로.
- **계정 없이** — 가입도, 로그인도, 등록할 것도 없습니다.
- 필요한 기능을 온라인에서 먼저 사용해 보세요. 브라우저에 저장된 기능은 오프라인에서 사용할 수 있습니다. 링크로 파일을 열려면 인터넷이 필요합니다.
- **주장을 직접 검증** — 오픈 소스 코드를 읽거나 직접 운영할 수 있습니다.

## 사용 방법

1. 편집기를 엽니다 — 가입 화면이 가로막지 않습니다.
2. 기기에서 DOCX·XLSX·PPTX·CSV 파일을 고릅니다.
3. 로컬에서 읽고 편집합니다. 처리는 서버가 아니라 브라우저에서 이루어집니다.
4. 끝나면 변경 사항을 내 기기로 내려받습니다.

## 자주 묻는 질문

### 무엇이 이 편집기를「프라이버시 우선」으로 만드나요?

파일이 WebAssembly 로 내 브라우저 안에서만 열리고 편집됩니다. 문서가 서버로 업로드되지 않으므로 처음부터 끝까지 기기에 남습니다.

### 파일이 업로드되는 일이 있나요?

아니요. 이 사이트에서 로컬 파일을 직접 열면 보기, 편집, 변환이 내 기기에서 이루어지므로 문서를 업로드할 필요가 없습니다.

### 파일을 비공개로 두려면 계정이 필요한가요?

계정도, 가입도, 로그인도 필요 없습니다. 편집기를 열면 바로 작업할 수 있고, 관리해야 할 클라우드 사본도 없습니다.

### 아무것도 업로드되지 않는다는 것을 확인할 수 있나요?

브라우저 네트워크 패널에서 로컬 파일의 열기, 편집, 저장을 확인하세요. 선택적 AI, 원격 URL과 호스트 통합 요청은 기본 로컬 편집과 별도로 확인하세요. 아니요. 이 사이트에서 로컬 파일을 직접 열면 보기, 편집, 변환이 내 기기에서 이루어지므로 문서를 업로드할 필요가 없습니다.

### 인터넷 연결이 없어도 동작하나요?

미리 준비하면 오프라인에서도 사용할 수 있습니다. 온라인에서 필요한 파일을 열어 편집과 내보내기를 사용한 후 연결을 끊고 확인하세요. 브라우저 데이터를 지우면 다시 연결해야 할 수 있습니다. 링크로 파일을 열려면 인터넷이 필요합니다.

### 탭을 닫으면 무엇이 남나요?

자동 저장을 켜면 마지막 편집 또는 열기 후 7일 동안 이 브라우저에 복구 사본이 보관됩니다. /history에서 삭제하거나 자동 저장을 끌 수 있습니다. 브라우저 데이터와 아직 저장되지 않은 수정은 사라질 수 있으므로 중요한 변경 사항은 파일로 저장하세요.
