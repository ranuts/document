로컬 파일 열기, 편집, 형식 변환은 내 기기에서 이루어지며 문서 처리 서버가 필요하지 않습니다. 소스 코드는 공개되어 있으며 직접 확인하거나 호스팅할 수 있습니다.

미리 준비하면 오프라인에서도 사용할 수 있습니다. 온라인에서 필요한 파일을 열어 편집과 내보내기를 사용한 후 연결을 끊고 확인하세요. 브라우저 데이터를 지우면 다시 연결해야 할 수 있습니다. 링크로 파일을 열려면 인터넷이 필요합니다.

## 사용 방법

1. 온라인에서 편집기를 열고 필요한 형식, 글꼴과 내보내기를 시험하세요. 연결을 끊은 뒤 같은 작업을 확인하고 오프라인 사용에 대비하세요.
2. PWA 설치는 선택 사항입니다. 브라우저 설치 기능이나 홈 화면에 추가를 사용할 수 있지만 모든 리소스의 캐시를 보장하지는 않습니다.
3. 필요한 기능을 온라인에서 먼저 사용해 보세요. 브라우저에 저장된 기능은 오프라인에서 사용할 수 있습니다. 링크로 파일을 열려면 인터넷이 필요합니다.
4. Chrome과 Edge에서는 첫 저장 때 파일을 선택하면 이후 변경 사항을 같은 파일에 저장할 수 있습니다. Safari, Firefox 등에서는 사본을 다운로드합니다.

- 필요한 기능을 온라인에서 먼저 사용해 보세요. 브라우저에 저장된 기능은 오프라인에서 사용할 수 있습니다. 링크로 파일을 열려면 인터넷이 필요합니다.
- **설치 가능한 PWA** — 홈 화면이나 데스크톱에 추가해 앱처럼 실행할 수 있습니다
- **어디서나 동작** — Chromebook, Windows, macOS, Linux, Android. 최신 브라우저면 됩니다
- DOCX·XLSX·PPTX·CSV 편집

## 자주 묻는 질문

### 정말 오프라인에서 동작하나요?

미리 준비하면 오프라인에서도 사용할 수 있습니다. 온라인에서 필요한 파일을 열어 편집과 내보내기를 사용한 후 연결을 끊고 확인하세요. 브라우저 데이터를 지우면 다시 연결해야 할 수 있습니다. 링크로 파일을 열려면 인터넷이 필요합니다.

### Chromebook에서도 동작하나요?

네. 최신 브라우저면 어디서나 동작합니다 — Chromebook, 노트북, Windows, macOS, Linux, Android.

### 파일이 업로드되나요?

아니요. 이 사이트에서 로컬 파일을 직접 열면 보기, 편집, 변환이 내 기기에서 이루어지므로 문서를 업로드할 필요가 없습니다.

### 어떤 형식을 편집할 수 있나요?

DOCX·XLSX·PPTX·CSV입니다. OnlyOffice를 사용합니다.

### 앱으로 설치하려면?

Chrome이나 Edge 주소 표시줄의 설치 아이콘, 또는 휴대폰·태블릿의 「홈 화면에 추가」를 사용하세요.

### 처음에는 온라인이어야 하나요?

온라인에서 편집기를 열고 필요한 형식, 글꼴과 내보내기를 시험하세요. 연결을 끊은 뒤 같은 작업을 확인하고 오프라인 사용에 대비하세요.

### 오프라인일 때 파일은 어디에 저장되나요?

네. Chrome과 Edge에서는 첫 저장 때 파일을 선택하면 이후 변경 사항을 같은 파일에 저장할 수 있습니다. Safari, Firefox 등에서는 사본을 다운로드합니다. 자동 저장을 켜면 마지막 편집 또는 열기 후 7일 동안 이 브라우저에 복구 사본이 보관됩니다. /history에서 삭제하거나 자동 저장을 끌 수 있습니다. 브라우저 데이터와 아직 저장되지 않은 수정은 사라질 수 있으므로 중요한 변경 사항은 파일로 저장하세요.
