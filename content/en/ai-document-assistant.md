Say what you want to do. Ask about content, work on text or organize data, and review changes before applying them.

## Get started

Enable the assistant, choose a local model or connect your AI service, then type your request. Model files stay in this browser. Opening another file may require preparing the model again, using cached files where available.

The default browser model is Qwen3 4B. Its estimated graphics memory use is about 3.43 GB; this is not the download size or total device memory use. It remains experimental. Previously downloaded smaller models can be removed under Downloaded models.

## Work with each file type

- Word: ask about content, draft text or refine selected paragraphs.

- Excel and CSV: read tables, enter data, generate number sequences, calculate totals or sort.

- PowerPoint: ask about slide text, add text, or add, duplicate and navigate slides.

- PDF: ask about, summarize or translate selectable text on the current page, or add a note to a specified page.

## Review before applying

Changes show their location and content. Edit a suggestion or ask for adjustments, then apply it when ready. Cancel unwanted changes; use the editor’s Undo after applying. Clearing or overwriting existing content requires confirmation. Read-only files can only be viewed.

If an adjustment fails or returns the same content, the original suggestion remains available while the document and selection stay unchanged.

## PDF scope

The assistant reads the current page, not the entire PDF. Text in scanned images is not recognized; unavailable text is reported. Notes are attached to a page and do not rewrite PDF body text or replace existing text. Use the original Word file to change body layout.

After adding notes, download the file as a PDF to keep them. The notes remain when you reopen that file. You can copy an answer without adding a note.

## Try asking

- “Summarize the current page.”

- “Add a note to page 2: Please check the budget.”

- “Fill A1 to A100 with numbers 1 to 100.”

## Keep in mind

AI can misunderstand requests or miss details. Check numbers, dates and names before applying. Local models process text on your device; connected AI services receive the text in your requests. Browser speech recognition may also use an online service. Dictated text stays in your draft and is not sent automatically.
