## 使い方

1. WebMCP API を提供するブラウザを使います（Chrome のオリジントライアル）。
2. **エディタ**を通常のタブとして開きます——ツールはトップレベルのページでのみ登録されます。
3. ブラウザの AI エージェントに、ドキュメントを開く・読む・変換する・書き出すよう依頼します。
4. WebMCP ツールの編集と変換はローカルですが、ブラウザエージェントは文書のテキストや書き出したファイルを取得し、自身の AI サービスに送信する可能性があります。機密情報を渡す前にエージェントのデータ方針を確認してください。

多くのウェブアプリは、AI エージェントから見ると不透明です。ボタンの並んだページが見えるだけで、どれがファイルを変換するのかを推測し、クリックが当たったことを祈るしかありません。WebMCP——W3C Web Machine Learning Community Group の提案——は、ページが自分にできることを型付きの入力を持つ構造化されたツールとして宣言できるようにし、その推測をまるごと省きます。このエディタは 7 つのツールを宣言します。

open_document_url, open_document_buffer, create_document, save_document, get_document_text, set_readonly, get_document_state. WebMCP ツールの編集と変換はローカルですが、ブラウザエージェントは文書のテキストや書き出したファイルを取得し、自身の AI サービスに送信する可能性があります。機密情報を渡す前にエージェントのデータ方針を確認してください。

初期設定はオフ · このブラウザのみ. [使い方](/ja/ai-document-assistant). 埋め込み先のアプリは書き出したファイルを受け取り、独自の方針でアップロードできます。

意図した制約が 2 つあります。ツールはエディタがトップレベルのページであるときにのみ登録されます——クロスオリジンの iframe では埋め込み側ページが `allow="tools"` を付与する必要があり、それは埋め込みの本来の使い方と衝突するため、埋め込まれたエディタは代わりに postMessage API で操作します。もう 1 つ、全文の読み取りはワープロ文書で利用できます。表計算とプレゼンテーションはこのエンジンでは全文を公開していないため、エージェントが「空のファイル」と誤解しかねない空の答えを返す代わりに、その旨を明示します。

## よくある質問

### WebMCP とは何ですか？

W3C Web Machine Learning Community Group の提案で、ウェブページが構造化されたツールを登録し、ブラウザ内の AI エージェントがそれを直接呼び出せるようにするものです。エージェントが画面を解釈してクリックする必要がなくなります。

### このエディタはどのツールを登録しますか？

7 つです: open_document_url、open_document_buffer、create_document、save_document、get_document_text、set_readonly、get_document_state。URL からもバイト列からも開ける、新規作成、書き出しや変換、本文の読み取り、読み取り専用の切り替え、現在の状態の報告をカバーします。

### どのブラウザが対応していますか？

WebMCP は Chrome でオリジントライアルとして利用できます。Firefox と Safari は対応を表明していません。API がない環境では何も登録されず、動作は変わりません。

### エージェントが作業するとき、ドキュメントはアップロードされますか？

WebMCP ツールの編集と変換はローカルですが、ブラウザエージェントは文書のテキストや書き出したファイルを取得し、自身の AI サービスに送信する可能性があります。機密情報を渡す前にエージェントのデータ方針を確認してください。

### エージェントはドキュメントの内容を読めますか？

ワープロ文書については、get_document_text が本文を返すため、エージェントは何も書き出さずに質問へ答えられます。表計算とプレゼンテーションはこのエンジンでは全文を読めないため、空の答えを返す代わりにその旨を報告します。

### 他のサイトに埋め込まれている場合も動きますか？

設計上、動きません。ツールはトップレベルのページでのみ登録されます。埋め込まれたエディタは postMessage の Embed API で操作してください。

### エージェントはファイルを PDF に変換できますか？

はい。save_document は出力形式を受け取るため、エージェントは DOCX・XLSX・PPTX を開いて PDF を書き出せます。すべて端末上で行われます。

### アカウントや API キーは必要ですか？

WebMCP ツールの利用にアカウントや API キーは不要です。基本的なファイルの読み込み、編集、形式変換はブラウザ内でローカルに実行され、ドキュメントのアップロードは不要です。 初期設定はオフ · このブラウザのみ. [使い方](/ja/ai-document-assistant). 埋め込み先のアプリは書き出したファイルを受け取り、独自の方針でアップロードできます。
